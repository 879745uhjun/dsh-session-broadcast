# 会话群发

把同一条消息一次发给 DeepSeek Harness 的多个会话。

对话输入框左侧工具栏会多出一个小喇叭图标。点开它，勾选要发送的会话，写一次消息，发送即可。每个被选中的会话都会收到同一条用户消息。

## 功能

- **一条消息，多个会话。** 列表来自侧边栏使用的同一份会话目录，显示标题、工作区、运行状态，以及「子代理」「新会话」标记。默认一个都不勾选，群发永远是一次明确的选择。
- **顺带认识箱子。** 装了箱子插件时，弹窗从侧边栏用的同一个路由读取分类：每行显示它所属的箱子（可多归属），顶部一排箱子筛选可以只看某个箱子、只看未分组或看全部。点父箱会连带它的子箱，所以在箱子里点「全选」就是发给这一整支。每次打开弹窗都会重新读取，箱子改名或会话换箱后立刻生效；没装箱子插件时，这一排筛选和行内标签会自动消失。
- **默认排队，也可打断。** 每个目标都走输入框相同的投递路径。开关关闭（默认）时用 `queue`：正在跑回合的会话会在当前回合结束后收到消息；打开开关则用 `steer`，直接中断对方当前回合并立即处理这条消息。开关下方的说明会随选择变化。
- **结果如实反馈。** 每次同时写入 3 个会话，并为每个目标显示结果：已排队，或 Host 返回的错误码与原因。「重试失败项」只重发失败的那些会话，输入框里的草稿会保留。

## 使用

1. 打开任意一个会话。
2. 点击输入框工具栏左侧的喇叭图标。
3. 需要时先筛选列表，再勾选会话。
4. 「打断当前回合」开关保持关闭即排队，打开即立即打断。
5. 输入消息，点击发送，或按 Ctrl/Cmd+Enter。

搜索会匹配会话标题、工作区名称和会话 id。「全选」和「清空」只作用于当前筛选出的行，所以「选中某个箱子 + 全选」就能发给整箱。

## 箱子

顶部那一排是筛选，不是设置：它不会改动任何归属。再点一次当前选中的箱子就取消筛选。胶囊用箱子自己的颜色，并显示当前会话数；子箱显示为 `父箱 › 子箱`。箱子插件没装或路由不可用时，筛选条和行内标签会一起隐藏，其余功能照常。

## 限制

- 只支持纯文本，附件和图片不能群发。
- 弹窗里的草稿只保留在当前页面，关闭应用后不保存。
- 会话可见范围由客户端会话控制器决定：当前配置下列不出来的会话也无法作为目标。
- 「已排队」表示 Host 已接受这条消息，不代表对方会话已经处理完成。

## 从 GitHub 安装

```sh
dsh plugin --profile desktop add github:879745uhjun/dsh-session-broadcast
```
